# Git Workflow

- Repository target: `https://github.com/incubateur-ademe/france-chaleur-urbaine-ifpen`.
- Default branch: `main`.
- Branch names: descriptive, no mandatory prefix.
- Commits: explain the why, not only the what.

## Protected files

- Never commit `.env`, `.env.local`, credentials or API keys.
- Review carefully: `package.json`, `pnpm-lock.yaml`, `.github/workflows/*`, and security tooling config.
