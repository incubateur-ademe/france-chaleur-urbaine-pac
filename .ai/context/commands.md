# Commands

## Development

```bash
pnpm install
pnpm dev       # Vite dev server, http://127.0.0.1:5173 by default
pnpm build     # Typecheck + production build
pnpm preview   # Preview the production build locally
```

## Quality

Run before delivering code changes:

```bash
pnpm lint
pnpm ts
pnpm test
```

Use `pnpm lint:fix` for mechanical Biome fixes.
